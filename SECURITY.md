# Security

v1 is a room tool. The current model lives in the README.

A Meeting link lets someone join and cast their own Ballot. The per-browser token only binds that browser to one current Ballot. It does not let them read or change someone else's.

File a public issue. Email votum@lsnd.se if you want it off the tracker. Issues are still the expected path. There is no bounty or SLA.

Known v1 limits are in the README. Meeting link as access, one browser token, no voter identity. Do not report those unless the code fails that model.
