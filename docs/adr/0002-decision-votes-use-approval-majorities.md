# Decision Votes use approval majorities

Status: accepted

Decision Votes are approval Votes for one proposal. Selection Votes remain the shape for choosing among alternatives. Each Decision Vote uses Simple majority by default or a fixed Qualified majority of two-thirds. Qualified majority excludes Abstentions by default, but the Organizer may enable a per-Vote setting that counts them. The expected participant count never affects the result.

Support must meet the selected Majority rule for the proposal to pass. If Support leads but misses the threshold, the result is rejected. A Support/Oppose tie remains a tie, and a Vote with no Support or Oppose Ballots has no result. The model does not treat Oppose as an independently qualified winner, add custom percentages, or add a default-to-Oppose setting. These alternatives would confuse proposal failure with an opposing majority and duplicate the purpose of Selection Votes.
